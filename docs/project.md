# Collab Editor (Decentralized, Rust+WASM + PromiseGrid)

This is a decentralized collaborative editor built with:
- Yjs for real-time peer-to-peer collaboration
- Rust compiled to WebAssembly (WASM) for high-performance text processing
- **PromiseGrid protocol integration** for decentralized computing messaging
- CodeMirror 6 as the text editor with undo/redo support
- Vite as the frontend bundler

No central server is required for collaboration or text processing. All operations happen client-side in the browser. **PromiseGrid protocol messaging** demonstrates authentic decentralized computing capabilities.

## Key Features

### Real-time Collaboration
- **Conflict-free collaborative editing** powered by Yjs CRDTs
- **Live cursor awareness** with user colors and names
- **Offline-first** with automatic sync when reconnected
- **Room-based isolation** via URL parameters

### WASM-Powered Text Processing
- **Document compression** (98% compression ratio) using Rust flate2
- **Live document statistics** (word count, character count, reading time)
- **Smart text formatting** with punctuation and spacing cleanup
- **Markdown formatting toggles** (Bold, Italic, Underline)
- **URL Link Helper** for converting URLs to markdown links
- **Professional document cleanup** with one-click formatting

### PromiseGrid Protocol Integration
- **Real CBOR message creation** with official 'grid' tag (0x67726964)
- **Live message generation** for every document edit and formatting action
- **Protocol-compliant messaging** following PromiseGrid specification
- **Decentralized computing demonstration** with authentic message structure
- **Console logging** of all PromiseGrid messages for verification
- **Export functionality** for PromiseGrid CBOR files
- **Content-addressable design** ready for distributed storage

### Editor Features
- **Undo/Redo** with buttons and keyboard shortcuts (Ctrl+Z/Ctrl+Y)
- **Export options** (txt, json, cbor, PromiseGrid CBOR, and binary snapshots)
- **User activity logging** and presence tracking
- **Typing indicators** and real-time user awareness

## WASM Text Processing Features

All text processing happens client-side using Rust compiled to WebAssembly:

### Document Search
- `search_document()` - Client-side full-text search with JSON results
- Smart case-insensitive matching with configurable sensitivity
- Returns match positions for UI integration and highlighting
- Optimized for large documents with instant response times

## Enhanced WASM Text Processing Features

### Document Search (`search_document`)
- Real-time full-text search with pattern matching
- JSON array output with start/end positions for each match
- Case-sensitive and case-insensitive search modes
- Efficient string processing for documents up to 25,000+ characters
- Browser-native performance with no server dependencies

### Document Statistics (`calculate_document_stats`)
- Real-time word count, character count, line count
- Reading time estimation (200 words/minute)
- Updates live in toolbar as user types

### Text Formatting (`format_text`)
- Clean up extra whitespace and line breaks
- Fix markdown header spacing  
- Format code blocks properly
- Clean up bold/italic syntax
- Fix punctuation spacing and parentheses

### Markdown Toggles
- `toggle_bold()` - Smart **bold** formatting toggle
- `toggle_italic()` - Smart *italic* formatting toggle  
- `toggle_underline()` - Smart __underline__ formatting toggle


### URL Processing (`convert_url_to_markdown`)
- Convert plain URLs to markdown link format
- Smart URL detection (http, https, ftp, www)
- Preserves existing markdown links

### Document Compression
- `compress_document()` / `decompress_document()`
- 98% compression ratio using gzip
- Reduces storage and transfer size

### PromiseGrid Protocol Functions
- `create_promisegrid_edit_message()` - Generate protocol messages for document edits
- `create_promisegrid_stats_message()` - Generate messages for document statistics
- `parse_promisegrid_message()` - Parse CBOR messages back to JSON
- `log_promisegrid_message()` - Console logging of protocol messages
- `export_document_as_promisegrid()` - Export documents as PromiseGrid CBOR

## Build Process

### WASM Module Generation
```bash
cd rust-wasm
wasm-pack build --target web --out-dir pkg
```

This generates:
- `pkg/rust_wasm.js` - JavaScript bindings
- `pkg/rust_wasm_bg.wasm` - WebAssembly binary
- `pkg/rust_wasm.d.ts` - TypeScript definitions

### Frontend Integration
The WASM module is imported and initialized in `src/wasm/initWasm.js`, then used throughout the application for text processing operations and PromiseGrid protocol messaging.

## PromiseGrid Integration Details

### Message Creation
Every formatting action creates authentic PromiseGrid CBOR messages:
- Official 'grid' tag (0x67726964) 
- Protocol hash identifying specification version
- Structured payload with message type and data
- User and document identification
- Timestamp for message ordering

### Console Output
During development, all PromiseGrid messages are logged:
```
PromiseGrid CBOR message created: 193 bytes
PromiseGrid Message: { "protocol_hash": "QmPromiseGridProtocolV1", ... }
Created PromiseGrid message for bold edit
```

### Export Functionality
Documents can be exported as PromiseGrid CBOR files through the dropdown menu, demonstrating protocol compliance and enabling integration with other PromiseGrid systems.
