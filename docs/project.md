# Collab Editor (Decentralized, Rust+WASM)

This is a decentralized collaborative editor built with:
- Yjs for real-time peer-to-peer collaboration
- Rust compiled to WebAssembly (WASM) for high-performance text processing
- CodeMirror 6 as the text editor with undo/redo support
- Vite as the frontend bundler

No central server is required for collaboration or text processing. All operations happen client-side in the browser.

## Key Features

### Real-time Collaboration
- **Conflict-free collaborative editing** powered by Yjs CRDTs
- **Live cursor awareness** with user colors and names
- **Offline-first** with automatic sync when reconnected
- **Room-based isolation** via URL parameters

### WASM-Powered Text Processing
- **Document compression** (98% compression ratio) using Rust flate2
- **Live document statistics** (word count, character count, reading time)
- **Smart text formatting** with punctuation and spacing cleanup
- **Markdown formatting toggles** (Bold, Italic, Underline)
- **URL Link Helper** for converting URLs to markdown links
- **Professional document cleanup** with one-click formatting

### Editor Features
- **Undo/Redo** with buttons and keyboard shortcuts (Ctrl+Z/Ctrl+Y)
- **Export options** (txt, json, cbor, and binary snapshots)
- **User activity logging** and presence tracking
- **Typing indicators** and real-time user awareness

## Commands

### Setup
```bash
make install
```
Install all npm dependencies.

### WASM Development
```bash
make wasm              # Build Rust WASM module
make wasm-clean        # Clean WASM build artifacts  
make wasm-rebuild      # Clean rebuild of WASM module
```

### Frontend Development
```bash
make build             # Build frontend (includes WASM)
make serve             # Start Vite dev server
make clean             # Remove build artifacts
make rebuild           # Clean rebuild everything
```

### Full Development Stack
```bash
make dev-all           # Start everything: WebSocket + Rust backend + frontend
make start             # Start WebSocket + frontend only
make stop              # Kill all development processes
```

### WebSocket Sync
```bash
make ws                # Start Yjs WebSocket server on port 1234
```

### Rust Backend (Optional)
```bash
make run-rust          # Run Rust backend for document persistence
make run-go            # Run Go backend (legacy support)
```

### Utilities
```bash
make open-room         # Open browser with new UUID room
make restart           # Kill stuck processes on development ports
```

## WASM Text Processing Features

All text processing happens client-side using Rust compiled to WebAssembly:

### Document Statistics (`calculate_document_stats`)
- Real-time word count, character count, line count
- Reading time estimation (200 words/minute)
- Updates live in toolbar as user types

### Text Formatting (`format_text`)
- Clean up extra whitespace and line breaks
- Fix markdown header spacing  
- Format code blocks properly
- Clean up bold/italic syntax
- Fix punctuation spacing and parentheses

### Markdown Toggles
- `toggle_bold()` - Smart **bold** formatting toggle
- `toggle_italic()` - Smart *italic* formatting toggle  
- `toggle_underline()` - Smart __underline__ formatting toggle

### URL Processing (`convert_url_to_markdown`)
- Convert plain URLs to markdown link format
- Smart URL detection (http, https, ftp, www)
- Preserves existing markdown links

### Document Compression
- `compress_document()` / `decompress_document()`
- 98% compression ratio using gzip
- Reduces storage and transfer size

## Build Process

### WASM Module Generation
```bash
cd rust-wasm
wasm-pack build --target web --out-dir pkg
```

This generates:
- `pkg/rust_wasm.js` - JavaScript bindings
- `pkg/rust_wasm_bg.wasm` - WebAssembly binary
- `pkg/rust_wasm.d.ts` - TypeScript definitions

### Frontend Integration
The WASM module is imported and initialized in `src/wasm/initWasm.js`, then used throughout the application for text processing operations.
