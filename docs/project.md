# Collab Editor (Decentralized, Rust+WASM)

This is a decentralized collaborative editor built with:
- Yjs for real-time peer-to-peer collaboration
- Rust compiled to WebAssembly (WASM) for export features
- CodeMirror as the text editor
- Vite as the frontend bundler

No central server is used. All collaboration happens in-browser.

## Project Structure

collab-editor/
├── rust-wasm/               # Rust code compiled to WebAssembly
│   ├── src/lib.rs           # Rust entry point
│   ├── Cargo.toml           # Rust crate config
│   └── pkg/                 # Generated by `wasm-pack build`
│
├── public/                  # Static assets served directly
│   └── index.html
│
├── src/                     # Frontend code
│   ├── app.js               # Main entrypoint: sets up Yjs, editor, UI
│   ├── wasm/initWasm.js     # Loads WASM and exports
│   ├── setup/               # Yjs and editor initialization modules
│   ├── ui/                  # Typing indicators, user list, logging
│   └── export/handlers.js   # Handles export to Markdown via WASM
│
├── package.json             # NPM configuration
├── vite.config.js           # Vite configuration
├── Makefile                 # Team command setup
└── .gitignore               # Git ignore rules

## Commands

### Setup

    make install

Install all npm dependencies.

### Build

    make build

Build the frontend using Vite.

### Development Server

    make serve

Run the Vite dev server.

### WebSocket Sync

    make ws

Start the Yjs WebSocket server on port 1234.

### Rust Backend (Optional)

    make run-rust

Run the Rust backend (used for some team configurations).

### Start Everything

    make start

Kills old processes, restarts Yjs and Vite, and opens a browser tab with a new room.

## Export Functionality

Rust-WASM is used to provide Markdown export capabilities in-browser. No server is required.

Ensure the WASM build output (`rust-wasm/pkg`) is available and properly linked in `src/wasm/initWasm.js`.

To generate the WASM package:

    cd rust-wasm
    wasm-pack build --target web

Ensure the generated `pkg/` directory exists and contains `rust_wasm.js`.
